# ランダム個人サイト・ブログ（randomsiteblog）

ボタンを押すと、個人サイト・個人ブログの記事をランダムで1件表示する小さなツールです。randomwikipedia の個人サイト／個人ブログ版です。

## 使い方

- **🎲 ランダムで記事を表示**：個人ブログの記事をランダムに1件選び、記事タイトルとブログ名を表示します。
- **記事を読む**：その記事を新しいタブで開きます。**ブログのトップへ** からブログ本体にも行けます。
- もう一度ボタンを押すと、別の記事が表示されます。

記事の候補はサーバー側で「にほんブログ村」の総合ランキング（公開ページ）から取得し（10分キャッシュ）、その中から1件を選びます。取得に失敗した場合は、長く続いている著名な個人サイトのシードリストから選びます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

※ テストでは外部通信を行わず、取得処理をモックに差し替えて検証します（ランキングHTMLのパースも固定フィクスチャで検証）。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。
